# Security Policy

Security and user privacy are important to ModelOrigen.

Please do not publicly disclose security vulnerabilities
through GitHub Issues.

If you discover a security issue, contact Origen Technologies
through the official contact method listed at:

https://modelorigen.in

Please include:
- affected page or feature
- browser/device
- steps to reproduce
- potential impact

Do not include sensitive personal information.

The ModelOrigen application source code is not distributed
through this repository.
