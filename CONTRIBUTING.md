# Contributing to ModelOrigen

Thank you for helping improve ModelOrigen.

The application source code is currently closed-source,
so this repository does not accept application-code contributions.

You can still contribute by reporting:

- mathematical or educational inaccuracies
- confusing explanations
- UI or accessibility problems
- browser/device bugs
- documentation issues
- useful feature suggestions

Before creating an issue, please check whether a similar issue
already exists.

Official product:
https://modelorigen.in
